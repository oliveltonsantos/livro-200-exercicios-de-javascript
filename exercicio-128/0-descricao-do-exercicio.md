## Descrição do exercício:

Crie uma função que utilize parâmetros default para criar um objeto "carro" com propriedades marca, modelo e ano, onde apenas modelo é obrigatório.

O foco deste exercício é o uso de parâmetros default para estabelecer valores padrão para funções. 

A função ilustra como podemos definir valores padrão para propriedades quando elas não são fornecidas na chamada da função.
